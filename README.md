# Lotus English Academy 🌟

A modern, responsive, and high-performance website for **Lotus English Academy**, based in Akurdi, Pune. This platform is designed to provide information about Spoken English, Soft Skills, and Interview Training courses while enabling seamless communication via WhatsApp.

## 🚀 Features

-   **Dual-Language Support**: Complete English and Marathi localization with a persistent language switcher.
-   **Modern UI/UX**: Premium design aesthetics using glassmorphism, smooth animations, and a curated color palette.
-   **Fully Responsive**: Optimized for everything from small mobile screens to large 4K displays.
-   **WhatsApp Integration**: Direct "One-Click" WhatsApp buttons for course inquiries and demo bookings.
-   **Interactive Gallery**: Tabbed gallery system to showcase classroom activities and events.
-   **Professional Contact Section**: Modern information cards and integrated Google Maps navigation.
-   **SEO Optimized**: Meta tags, semantic HTML, and fast loading times for better search engine ranking.

## 🛠️ Tech Stack

-   **Frontend**: React 18, TypeScript, Vite
-   **Styling**: Tailwind CSS, Vanilla CSS (Design System)
-   **Components**: Shadcn UI, Radix UI, Lucide Icons
-   **Animations**: CSS Transitions & Intersection Observer API
-   **Deployment**: Optimized for static hosting (Vercel, Netlify, etc.)

## 📦 Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or higher)
-   [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/lotus-english-academy.git
    cd lotus-english-academy
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Build for production:
    ```bash
    npm run build
    ```

## 📂 Project Structure

-   `src/pages/Index.tsx`: Main landing page content and logic.
-   `src/index.css`: Global design system and custom styling.
-   `public/assets/`: Image assets, logos, and gallery photos.
-   `src/components/ui/`: Reusable UI components (Toasts, Buttons, etc.).
